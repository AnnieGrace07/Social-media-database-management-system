
# Social Media Database Management System

## Project Overview

This project was developed as part of an academic coursework for SQL Analysis

The objective of the project was to design and implement a relational database for a social media application using database design principles, normalization, ERD modeling, SQL Server, and SQL queries.

## Project Objectives

- Create an Entity Relationship Diagram (ERD) using Crow’s Foot Notation
- Design entities and attributes in Third Normal Form (3NF)
- Build a physical database in Microsoft SQL Server
- Populate tables with sample data
- Write SQL queries to answer business questions

## Tools Used

- Microsoft Visio
- Microsoft SQL Server
- SQL
- Database Normalization
- ERD Design

## Main Entities

### User
A user can create posts, make comments, like posts, join groups, and have friends.

### Post
A post is created by a user and can have comments and likes.

### Comment
A comment is made by a user and belongs to a post.

### Group
A group can have multiple members and posts.

## Business Questions Answered

1. Find the most recent post by each user
2. Retrieve groups with more than two members
3. Retrieve the top 5 users with the most posts
4. Retrieve posts with more than 3 likes
5. Get the number of posts each user has made
6. Get all users who have not made any post
7. Get the number of posts each group has
8. Retrieve all groups a specific user has joined along with the date they joined
